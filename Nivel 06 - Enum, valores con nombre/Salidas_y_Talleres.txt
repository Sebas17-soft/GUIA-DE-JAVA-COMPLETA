TABLA DE RESPUESTAS Y JUSTIFICACIÓN:
┌─────────┬──────────────────┬─────────────────────────────────────────────────────────────┐
│ Espacio │ Palabra Elegida  │ ¿Por qué va ahí? (Una frase)                                │
├─────────┼──────────────────┼─────────────────────────────────────────────────────────────┤
│ 1       │ enum             │ Declara el tipo enumerado Leche.                            │
│ 2       │ final            │ Hace que el campo recargo sea inmutable dentro de cada enum.│
│ 3       │ Leche            │ Constructor del enum (mismo identificador del tipo).        │
│ 4       │ switch           │ Inicia la expresión switch de flechas para evaluar this.    │
│ 5       │ default          │ Rama que responde false para las leches de origen animal.   │
│ 6       │ values           │ Método estático para iterar sobre todas las leches.         │
│ 7       │ recargo          │ Método accesor para imprimir el costo extra de la leche.    │
└─────────┴──────────────────┴─────────────────────────────────────────────────────────────┘

PREGUNTAS DE CONTROL:
1. Pregunta: ¿Por qué el switch del espacio 4 necesita el default del espacio 5? ¿Qué pasaría si escribes los 4 casos sin default?
   Respuesta: Si listas explícitamente los 4 casos (`case ENTERA, DESLACTOSADA -> false; case AVENA, ALMENDRAS -> true;`),
   el compilador reconoce que es exhaustivo y NO necesita `default`. Se usó `default` como atajo para agrupar todas
   las demás opciones que no sean vegetales.

2. Pregunta: Si en el espacio 6 escribes valueOf, ¿qué error esperas?
   Respuesta: `error: method valueOf in enum Leche cannot be applied to given types`: `valueOf`
   requiere un argumento `String`, no puede llamarse sin argumentos para iterar en un `for`.
